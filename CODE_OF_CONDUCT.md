# Code de conduite

## Notre engagement

En tant que membres, contributeurs et responsables de ce projet, nous nous engageons à faire de la participation à Modrise une expérience sans harcèlement pour tout le monde, quels que soient l'âge, la corpulence, le handicap visible ou invisible, l'origine ethnique, les caractéristiques sexuelles, l'identité et l'expression de genre, le niveau d'expérience, l'éducation, le statut socio-économique, la nationalité, l'apparence personnelle, la race, la religion ou l'identité et l'orientation sexuelles.

## Nos standards

Exemples de comportements qui contribuent à un environnement positif :

- faire preuve d'empathie et de bienveillance envers les autres ;
- respecter les opinions, points de vue et expériences différents ;
- donner et accepter avec grâce les retours constructifs ;
- assumer ses erreurs, s'excuser auprès des personnes affectées et apprendre de l'expérience.

Exemples de comportements inacceptables :

- l'utilisation de langage ou d'images sexualisés ;
- le trolling, les commentaires insultants ou dénigrants, les attaques personnelles ou politiques ;
- le harcèlement public ou privé ;
- la publication d'informations privées d'autrui sans autorisation explicite.

## Application

Les comportements abusifs peuvent être signalés aux responsables du projet via les issues GitHub ou une security advisory pour les cas sensibles. Toutes les plaintes seront examinées rapidement et équitablement.

Ce code de conduite est adapté du [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
